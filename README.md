# Appliance Energy Consumption: TV Data Visualisation

An interactive web application built for the **COS30045 Data Visualisation** unit. This project explores energy consumption data for televisions in the Australian market, providing consumers with simple, visual insights to help them make smarter, energy-efficient choices.

##  Target Audience (T03)
Based on the storyboard created in Miro, the target audience for this website is:
*   **Australian consumers** looking to buy a new TV.
*   They want **affordable, energy-efficient, and good-sized TVs**.
*   They prefer **simple visual insights** over technical detail.

##  Data Story & Key Insights (T03)
The website answers 6 key questions based on an Australian Government dataset on TV energy use:

1.  **What TV screen technologies are available?** 
    *   *Insight:* Most TVs in Australia are LCD LED, while OLED is less common.
2.  **What screen sizes are most common?**
    *   *Insight:* 40-inch and 43-inch are the most common sizes, followed by 60-inch.
3.  **Which brands dominate the market?**
    *   *Insight:* Hisense dominates the market with the largest number of models, followed by JVC and TCL.
4.  **Which screen types use the least power?**
    *   *Insight:* LCD TVs consume the least power, while OLED uses slightly more.
5.  **How does screen size affect power use?**
    *   *Insight:* There is a positive correlation—larger TVs use more power.
6.  **Do larger TVs mean worse star ratings?**
    *   *Insight:* Star ratings are fairly distributed; bigger TVs can still be efficient.

**Final Takeaway:** When choosing a TV, balance size, brand, and efficiency. A 55-inch LED TV is a common and energy-smart choice.
